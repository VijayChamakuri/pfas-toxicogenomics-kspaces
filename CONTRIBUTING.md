# Contributing

Contributions that improve reproducibility, testing, documentation, or explicitly scoped analysis
methods are welcome through pull requests.

1. Open an issue describing the proposed scientific or engineering change.
2. Keep scientific decisions explicit, including thresholds, backgrounds, null models, and testing
   families.
3. Add or update tests for code changes.
4. Regenerate notebooks through their builders. Do not manually edit generated `.ipynb` files.
5. Run the verification commands in the root README.
6. Do not add raw individual-level data, credentials, collaborator documents, local paths, or
   third-party material without documented redistribution permission.

Scientific interpretation changes require evidence in executed outputs and review of the claim
language in `FINDINGS.md` and the root README.
