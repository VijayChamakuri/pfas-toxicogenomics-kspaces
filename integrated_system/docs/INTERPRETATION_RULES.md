# Interpretation rules and known failure conditions

## Rules for scientific statements

1. A threshold-defined DEG is evidence of detection under one contrast, not proof that the gene is unaffected elsewhere.
2. A continuous logFC pattern is an estimated association across the ten conditions. It is not a causal mechanism.
3. The ten chemicals are conditions, not independent biological replicates for broad chemical-class inference.
4. Consensus assignment strength measures agreement across repeated optimizer fits. It does not measure biological effect size or external reproducibility.
5. Raw correlation between five-element module-percentage profiles is retracted because its null distribution is intrinsically high. It must not be reported as chemical-similarity evidence.
6. Null-adjusted similarity and structure-activity results remain exploratory until multiplicity, label uncertainty, and external validation are addressed.
7. GO enrichment statements must name the tested universe, mapping loss, ontology source, namespace, and family-wide multiple-testing method.
8. A neural backend parity benchmark uses synthetic workflow requests only. It cannot support a PFAS biological conclusion.
9. Adaptation loss alone does not demonstrate valid workflow generation. Typed validation and deterministic scientific rules remain authoritative.
10. A plan requiring scientific judgment must stop at a review-ready state. Only a separately supplied approval bound to the exact plan digest can authorize execution.

## Mandatory abstention conditions

The system abstains when required metadata is missing, the requested field or artifact does not exist, sample-level inference is requested from contrast summaries, the sample size cannot support the requested conclusion, the tool or operation is outside the allowlist, evidence hashes cannot be revalidated, or the request asks the system to promote an exploratory result to a confirmed mechanism.

## Human review record

Tests may use an object labeled as a validation fixture to verify approval-binding code. A fixture is not a scientific approval. A public result must record the reviewer identity, decision, plan digest, evidence hashes, code version, inputs, and execution identifier.
