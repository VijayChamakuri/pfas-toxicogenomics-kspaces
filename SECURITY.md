# Security policy

Please report potential credential exposure, unsafe workflow execution, dependency vulnerabilities,
or privacy issues through a private GitHub security advisory. Do not open a public issue containing
secrets, personal data, or unpublished research material.

The planning service is designed around allowlisted operations and human review. It is not an
authorization boundary for arbitrary code execution and should not be exposed to untrusted networks
without deployment-specific authentication, rate limiting, logging, and access controls.
